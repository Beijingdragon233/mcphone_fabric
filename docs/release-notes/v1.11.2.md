# 下一版本

- 工程审查后收紧新版群存档的入群历史边界与收藏 JSON 字段校验；群图片改用完整临时文件替换并修复残缺内容重试。固定群与资料状态协议编号，集中断线清理和群请求策略，资料票据耗尽不再导致页面异常。

- 统一美西螈标题、搜索提示、联系人入口、申请行和底栏的文字/图标对齐；建群与邀请勾选框移入卡片，几何勾号居中并避让姓名。邀请加号去掉圆圈，聊天返回及邀请入口使用中性色和粉色强调。

- 美西螈首页加号增加「创建群聊」「添加好友」菜单与对应图标，支持输入群名称、搜索并选择好友建群。
- 修复创建群聊菜单需要二次点击的问题；群名改为选填，选好友即可创建，未填时使用“新群聊”，空名单显示明确提示。
- 增加独立联系人页面，支持好友名称搜索、英文/中文拼音 A–Z 分组、# 分类和字母索引跳转，保留方形头像及在线状态。
- 添加独立新朋友申请页面；当前只显示在线玩家的申请。联系人群聊分类接入 A–Z 目录与搜索，群通知接入持久化的待处理入群邀请。
- 联系人与消息共用底栏；从联系人进入聊天或添加好友后，返回联系人。
- 群聊支持群名、人数、发送者昵称、文字与图片、选字复制及仅删除自己的记录；个人删除、群成员和已读随世界保存。
- 群头像按人数居中拼合，移除嵌套描边；群消息缩小并贴近昵称，己方也显示昵称，文字与图片的命中随新排版同步。
- 增加群成员详情与二次确认：普通成员退出，群主解散；离群后立即失去群历史和图片访问权限。
- 首页搜索支持按好友名、群名筛选会话，保留时间排序；名称匹配与联系人一致。两页搜索栏统一尺寸，清理“暂未开放”旧提示，传送图标移除外框并保留原点击区域。
- 群详情增加方形成员头像网格、完整成员列表、邀请好友和群主修改名称；操作经过服务端确认，拒绝或超时保留草稿。
- 建群选好友及所有成员邀请好友均须被邀请者本人同意；群通知支持同意、拒绝和离线保存。同意前不成为群成员，新成员只可读取同意后的消息，过期/邀请人离群/解散会撤销邀请。
- 待处理邀请与入群边界随存档保存，旧群格式 1/2 可读取并迁移至格式 3，客户端和服务端必须同时更新。
- 群聊复用现有输入、气泡和图片组件，群与私聊的缓存、导航和上传回声隔离；客户端与服务端需要同时更新。
- 增加美西螈“我”页面，只保留资料、收藏、专用设置、GitHub 和赞助入口；赞助暂只显示入口提示。
- 文字消息支持右键收藏、独立收藏列表、全文查看/复制和移除，本机保存按账号与服务器隔离；删除原消息不影响收藏。
- 备注作为公开个人介绍保存在当前服务端，好友与群成员头像可查看资料，只有本人可以编辑；客户端与服务端须同时更新个人资料协议。
