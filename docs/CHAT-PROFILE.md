# 美西螈个人页、介绍与文字收藏

本页只提供玩家资料卡，以及按“收藏、GitHub、赞助、设置”排序的四个入口。头像保持 Minecraft 方形风格，不显示微信号、二维码或状态按钮。赞助目前只有入口提示，没有支付或跳转。

菜单使用用户提供的 96×96 透明图标，设置为 Heroicons D 款六齿齿轮。PNG 原样复制，按可见轮廓统一 8 像素最长边并居中，随主题文字着色；右键消息的收藏也复用同一素材。原稿与来源在 `docs/assets/chat-ui/menu-actions-96px/`，许可随包保留。

## 模块职责

| 位置 | 职责 |
| --- | --- |
| `client/ChatProfile` | 个人页及内部页面的协调、导航意图 |
| `client/ChatProfileLayout`、`ChatProfileUi` | 不可变卡片与四行布局、共用图文行和图标 |
| `client/ChatProfileDetails` | 介绍草稿、读取/保存票据和服务器确认 |
| `client/ChatFavoritePane` | 收藏列表、完整正文查看、复制与移除 |
| `client/favorite/FavoriteText` | 完整文字的不可变收藏快照 |
| `client/favorite/FavoriteStore` | 限量读取、原子替换文件、写失败保护 |
| `client/favorite/ChatFavorites` | 当前账号、服务器或单人世界对应的文件定位 |
| `client/profile/ProfileClientCache` | 有上限、带有效期的客户端票据收件箱 |
| `profile/ProfileBook`、`ProfileData` | 服务端介绍规则与主世界存档 |
| `profile/net/ProfileWire`、`ProfileServer` | 限长协议、权限、限流和服务端执行 |
| 版本层/加载器层的 `profile/net` | 包装载荷、注册及线程切换，复用共享业务 |

页面视图留在现有 `client` 包，复用包内的字号、半透明面板和单行输入；保存和协议实现分目录维护。消息菜单通过注入回调交出收藏意图，不依赖个人页。

## 可见性与保存

- “备注”是公开的个人介绍，上限 160 个 UTF-16 单元；不修改玩家名。清洗格式符及控制字符，可以清空。
- “云端”使用当前 Minecraft 服务端：数据保存在主世界 `data/mcphone_profiles.dat`，不是跨服务器账户服务。好友头像、群详情中的成员头像可打开公开资料；离线资料也由服务端读取。
- 服务端采用当前连接的玩家身份，只允许修改本人介绍，200ms 请求间隔；读取介绍是公开操作。客户端收到成功回声才更新显示值，失败保留草稿。
- 页面关闭/换服取消客户端票据，迟到回声不能修改新页面。取消等待不能撤销已经在服务端执行的保存；重新打开会读取最终服务端值。
- 收藏只支持文字，始终保存整条正文，选中文字不缩小收藏范围。源消息 ID、来源会话、发送者、会话名称和时间一并保存。正文查看页可以复制或移除。
- 收藏按玩家 UUID 和服务器地址摘要隔离；单人游戏按世界目录隔离。文件为 `config/mcphone/chat/favorites/<玩家 UUID>/<服务器或世界摘要>.json`。
- 上限 512 条、文件上限 2MiB。相同会话的同条消息不重复收藏，群聊和私聊分开识别。删除源消息、退出群聊不会自动删除已收藏的文字快照。
- 写入成功后才替换内存快照；读取失败时保留原文件并锁定写入，避免损坏文件被空列表覆盖。个人资料存档的未知格式和损坏 NBT 同样保留原文并锁定。
- 收藏格式 1 的字段与类型由 `FavoriteCodec` 严格检查；缺失会话类型或时间不能用 false/0 填补。读取最多 2MiB 加一字节，非法 UTF-8 拒绝；资料页遇到请求票据耗尽或发送异常只显示失败。四个平台的断线清理由 `ChatClientLifecycle` 集中维护。

## 设置与协议

美西螈专用设置页目前包含“编辑备注”“管理收藏”以及公开介绍/本机收藏的保存说明。所有入口均连接当前实现，没有新增未实现的开关。

个人资料使用 `profile_request_v1`、`profile_response_v1`。Forge 整数通道由 10 升至 11，NeoForge 注册协议由 7 升至 8；Fabric 检查资料载荷支持。客户端和服务端须同时更新。群协议和群存档格式不变。

## 验证

自动化验证覆盖介绍权限与清洗、NBT 和网络往返、关闭/超时/换服回声拒收、草稿及确认状态、个人页导航、手机和平板的卡片边界、完整正文收藏、独立来源、文件重载和移除、重复/容量限制、写失败及损坏文件保护。

游戏实测仍需检查中英文昵称和备注、中文输入光标、方形头像及图文对齐、文字右键收藏、收藏长文滚动、移除后重启、两个玩家查看介绍、服务端重启和换服隔离。构建成功不代表视觉验收完成。
