# 联系人界面

联系人是美西螈内的独立页面。顶部为添加好友、搜索、新朋友、群通知；分类只有好友与群聊，没有特别关心。底栏与消息页及个人页共用，发现继续预留；“我”页见 [个人页架构](CHAT-PROFILE.md)。

联系人与群通知的标题都按完整内容区居中。群通知展示待处理的入群邀请，统一由机身底部返回键返回联系人；通知页不设置右上角返回箭头，也不保留添加好友按钮的隐藏命中区。消息与联系人搜索栏共用 12 像素高度和相同输入控件，提示均为“搜索”。

| 文件 | 职责 |
| --- | --- |
| `ChatContacts` | 页面生命周期、缓存投影、分类与群通知入口、向手机交出导航意图 |
| `ChatGroupNotices` | 入群邀请收件箱、按邀请 ID 命中的同意/拒绝按钮、等待确认、失败重试和票据取消 |
| `ChatContactDirectory` | 不可变目录、名称搜索、中文拼音/英文排序、A–Z 与 # 分组 |
| `ChatContactScroll` | 分组标题和好友行的统一坐标、滚动与字母跳转的视口约束 |
| `ChatContactPane` | 分组、索引、列表滚动视口与坐标命中 |
| `ChatContactRow` | 联系人、建群与邀请共用的卡片视图和布局；选择标志位于卡片内，不持有选择状态 |
| `ChatContactSearch` | 原版 EditBox、缩放坐标、焦点与输入，不接触好友或网络 |
| `ChatNavigationBar` | 消息与联系人共用底栏的外观和命中 |
| `ChatAddContact` | 添加好友与独立新朋友页共用的申请行及原有发包逻辑 |

这些类位于 `shared/src/main/java/com/november/mcphone/feature/chat/client/`；内部组件保持包内可见。`PhoneScreen` 只负责生命周期、输入分发和导航；从联系人打开会话或添加好友，返回仍回联系人。关闭添加好友页时，续开记录归到实际来源页面。

## 数据与排序

服务端 `ChatService.buildConversations` 返回全部好友，包括未聊天与离线好友。联系人投影这份不可变摘要，不改变消息首页原有的时间排序。查询或缓存快照改变才重建目录；标题、好友行、索引使用同一组数据和坐标。

拼音索引使用 Minecraft 已有的 ICU4J，固定 `zh@collation=pinyin` 并加入英文标签。英文与普通中文按 A–Z 分组，数字、符号及未映射字符归到末尾 #；组内按拼音比较，同名以 UUID 排序。多音字遵循 ICU 默认读音，暂不提供玩家自定义读音。搜索支持名称子串，忽略大小写和首尾空白，并兼容全角字母；未实现拼音缩写搜索。

ICU API 的跨版本证据记录在 `versions/third-party-apis.json`。不增加玩家依赖、不重复打包 ICU。官方说明：[AlphabeticIndex](https://unicode-org.github.io/icu-docs/apidoc/released/icu4j/com/ibm/icu/text/AlphabeticIndex.html)。

## 当前功能边界

- 群聊分类接入真实群摘要，按群名 A–Z 排列并支持名称搜索；群通知展示在线与离线持久邀请，只收到本人邀请。联系人入口显示待处理数量，通知页可同意或拒绝；同意前不进入群目录。群业务、协议与存档见 [群聊架构](CHAT-GROUPS.md)。
- 新朋友是独立页面，过滤现有在线玩家摘要中的收到/发出的申请，沿用服务端确认逻辑。目前协议只返回在线玩家的关系，所以离线申请尚不能展示；页面明确说明此限制。完整离线申请列表需要后续增加独立数据契约。
- 添加好友仍使用原有在线玩家页。头像沿用当前客户端已加载的皮肤缓存。

## 验证

标题、搜索、入口和按钮标签通过 `ChatLayout.labelTop/labelLeft` 保留小数计算视觉中心；纵向沿用消息正文已校准的默认字形高度与半像素顶沿偏移，水平去掉行尾间距，消息正文坐标不受影响。搜索图标、提示和实际输入共用纵向中心。选人卡片完整占用行宽，勾选框放在卡片内，姓名截断为选择列让位；勾号及无圈加号按局部几何绘制，不依赖特殊字符的字形。聊天返回和邀请使用字体中性色，悬停使用粉色强调。

`ChatUiAlignmentTest` 验证上述生产几何、图标透明边距和卡片内勾选区域的实际建群/邀请点击。

`ChatContactDirectoryTest` 覆盖中文/英文/重音字符首字母、稳定排序、过滤和快照；`ChatContactsInteractionTest` 覆盖滚动、字母跳转、边界、导航意图与申请过滤；`ChatContactSearchTest` 使用真实 EditBox 检查输入、选区、焦点、长度及生命周期。`ChatGroupNoticesTest` 覆盖生产按钮、待确认隔离、同意/拒绝、失败重试、滚动后旧命中失效和离页取消。四个平台仍须跑完整构建和仓库检查。

游戏内验收需检查小屏幕姓名截断、字母索引清晰度、中文输入、搜索无匹配、群聊切换、联系人打开会话及返回、好友申请接受、GUI/HUD 缩放。这些视觉与交互检查不能以编译成功替代。
